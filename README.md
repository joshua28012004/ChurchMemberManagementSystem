Church Member Management System



A web-based application designed to help churches manage member information, donations, birthdays, events, and administrative records efficiently.



📌 Project Overview



The Church Member Management System digitizes common church administration activities and reduces the need for manual record keeping.



The system provides a centralized platform for managing church members, tracking donations, organizing events, and viewing useful reports.



✨ Features



\- 🔐 Secure administrator login

\- 👥 Add, edit, search, and delete member records

\- 🎂 Birthday reminders for church members

\- 💰 Donation management and receipt generation

\- 📅 Add, edit, view, and delete church events

\- 📊 Reports and data summaries

\- 🖼️ Member profile photo uploads

\- 🛡️ Input validation and database security measures

\- 📱 User-friendly dashboard



🛠️ Technologies Used



\- Frontend: HTML, CSS, JavaScript, Bootstrap

\- Backend: PHP

\- Database: MySQL

\- Local Development Server: XAMPP

\- Version Control: Git and GitHub



🗂️ Main Modules



1\. Administrator Login

2\. Dashboard

3\. Member Management

4\. Donation Management

5\. Birthday Reminders

6\. Event Management

7\. Reports



⚙️ Installation and Setup



Requirements



\- XAMPP

\- Apache

\- MySQL

\- Web browser



Steps



1\. Install XAMPP.



2\. Copy the project folder into:

&#x20;

&#x20;  "C:\\xampp\\htdocs\\"



3\. Start Apache and MySQL in XAMPP.



4\. Create a MySQL database named:

&#x20;

&#x20;  "church\_management"



5\. Configure the local database settings in the private configuration file.



6\. Open the application in your browser:

&#x20;

&#x20;  "http://localhost/ChurchManagement/"



🔒 Security Notes



\- Database configuration files should not be uploaded to public repositories.

\- Member-uploaded photos are excluded from Git tracking.

\- Database backup files should be stored securely.

\- Use strong administrator passwords in production.

\- Additional security configuration is required before public deployment.

To provide churches with a simple and efficient digital system for managing members, donations, birthdays, events, and administrative information.
